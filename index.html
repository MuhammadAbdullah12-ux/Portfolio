01 · rag-engine

01

YomoLoco / RepoMind

A retrieval-augmented generation engine for GitHub repositories.

Ingests a repo's README, issues, and PRs, filters out bot noise, and keeps a vector index in sync with the source using SHA-256 differential sync — so re-indexing only touches what actually changed. Dense embeddings via FastEmbed, vector search via Qdrant, relational metadata via SQLModel, all served through a FastAPI backend.

02 · resumify.app

02

Resumify

AI-powered resume analysis and job-fit matching.

Parses resumes and job descriptions, then scores relevance using a combination of NLP-based semantic similarity and exact skill matching — built to reduce both false positives and false negatives compared to keyword-only ATS tools. Also includes ATS compatibility checks, skill-gap analysis, and candidate ranking for recruiters.

CourseForge

A two-role learning platform with an AI tutor built in.

Instructors draft courses with AI assistance; students learn and chat with a lesson-scoped AI tutor as they go. Role-based routing and middleware separate the student and instructor experiences from one codebase, with the Gemini API handling course generation, tutoring, and auto-graded quizzes.
