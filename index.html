YomoLoco / RepoMind

View Source ↗

A retrieval-augmented generation engine for GitHub repositories.

Ingests a repo's README, issues, and PRs, filters out bot noise, and keeps a vector index in sync with the source using SHA-256 differential sync — so re-indexing only touches what actually changed. Dense embeddings via FastEmbed, vector search via Qdrant, relational metadata via SQLModel, served through a FastAPI backend.

Python FastAPI FastEmbed Qdrant SQLModel
Retrieval AccuracyGrade A+ (15 eval queries)
EmbeddingFastEmbed (384-dim)
Vector StoreQdrant
Sync MethodSHA-256 Differential

Resumify

AI-powered resume analysis and job-fit matching platform.

Parses resumes and job descriptions, then scores relevance using a combination of NLP-based semantic similarity and exact skill matching — built to reduce both false positives and false negatives compared to keyword-only ATS tools. Includes ATS compatibility checking, skill-gap analysis, and automated candidate ranking.
